# InStock Astana

Русскоязычный визуальный прототип обувного магазина. Чистые HTML, CSS и JavaScript, без сборки и внешних JS-зависимостей.

## Запуск

Требуется Node.js 22 или новее.

```powershell
cd instock-astana
node server.mjs
```

Открыть http://127.0.0.1:5890.

## Экраны и сценарии

- Главная: `#/`
- Каталог, поиск, категории, размеры, сортировка: `#/catalog`
- Карточки восьми демонстрационных товаров: `#/product/city-white`
- Страница бренда: `#/about`
- Размерная сетка, корзина, изменение количества, удаление и просмотр заказа.
- Адаптивные макеты для мобильного и настольного экрана.

## Ограничения

Это только визуальный прототип. Товары, описания, цены и размеры условные. Корзина существует только в памяти текущей вкладки и сбрасывается при перезагрузке. Заказы не оформляются. Нет платежей, API, базы данных, пользовательских аккаунтов или серверной бизнес-логики. `server.mjs` служит только для локального просмотра статических файлов.

Файлы сайта находятся в `dist/`. Для статического хостинга не требуется сборка. Навигация использует hash-маршруты. Информация о визуальных материалах — в `ASSETS.md`.

## Проверка синтаксиса

```powershell
node --check dist/app.js
node --check server.mjs
```

## Публикация на Vercel

Импортировать репозиторий `nalrematvonessahk/instock-astana` в Vercel.
Корневая папка проекта — корень репозитория (`./`).

В `vercel.json` задан пресет Other, отключены установка зависимостей и сборка,
а папкой публикации выбрана `dist`. Локальный сервер `server.mjs` на Vercel
не запускается. Для маршрутов `#/catalog` и `#/product/...` rewrites не нужны.

После подключения GitHub изменения в ветке `main` публикуются автоматически.
Доступ к сайту определяется настройками Vercel; приватность GitHub-репозитория
сама по себе не делает опубликованный сайт приватным.
