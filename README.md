# В наличии

Сервис поиска обуви в офлайн-магазинах Астаны. Показывает, в каком магазине города нужная модель есть в вашем размере прямо сейчас, и позволяет забронировать пару на 24 часа, чтобы приехать на примерку наверняка.

Мы не магазин и не маркетплейс: ничего не продаём, не принимаем оплату и не доставляем. Оплата — в магазине при получении.

Это визуальный прототип на демо-данных. Чистые HTML, CSS и JavaScript в `dist/`, без сборки и внешних JS-зависимостей.

## Размеры — ключевая сущность

Позиция определяется тройкой «модель + магазин + размер». У каждой позиции в `dist/data.js` есть карта остатков по размерам, например `{ "38": 2, "39": 0, "41": 1 }`. Размерный ряд 36–45 для взрослой обуви и 28–35 для детской.

- «Мой размер» выбирается на главной или в фильтре поиска, сохраняется в браузере и подставляется на всех экранах.
- Статус наличия, число магазинов, цены и точки на карте считаются по выбранному размеру.
- Выбор размера на экране модели меняет только этот экран и адрес страницы, сохранённый размер не трогает.

## Запуск

Требуется Node.js 22 или новее.

```sh
node server.mjs
```

Открыть http://127.0.0.1:5890.

## Экраны

- `#/` — главная: поиск по запросу, выбор своего размера, поиск по фото, категории, «как это работает».
- `#/visual` — поиск по фото: загрузка изображения, имитация обработки, похожие модели с процентом совпадения.
- `#/search` — результаты: фильтр «Мой размер» первым, категория, цена, наличие сегодня, расстояние; сортировка по близости, цене и рейтингу магазина.
- `#/product/<id>` — модель: сводка по размерам в городе, список магазинов с размерной сеткой в каждой строке и схематичная карта Астаны.
- `#/reserve/<offerId>?size=<размер>` — бронирование с явным выбором размера.
- `#/reservations` — мои брони с таймером и статусами, `#/reservations/<id>` — экран брони с кодом.
- `#/merchant` — панель магазина: демонстрационный вход, остатки по размерам, входящие брони, статистика.

## Ограничения прототипа

- Магазины, модели, цены и остатки условные.
- Поиск по фото имитирован: модели распознавания нет, соответствия заданы заранее в демо-данных.
- Оплаты, доставки, аккаунтов, API и базы данных нет.
- Брони, выбранный размер и правки из панели магазина хранятся в `localStorage` этого браузера. Бронь действует 24 часа с момента создания.
- Вход в панель магазина демонстрационный, без авторизации.
- Карта — стилизованная SVG-схема, без внешних картографических сервисов. Расстояния считаются от условной точки «Вы здесь».


## Публикация на Vercel

Импортировать репозиторий в Vercel, корневая папка проекта — корень репозитория (`./`).

В `vercel.json` задан пресет Other, отключены установка зависимостей и сборка, папка публикации — `dist`. Локальный сервер `server.mjs` на Vercel не запускается. Для hash-маршрутов rewrites не нужны.

После подключения GitHub изменения в ветке `main` публикуются автоматически. Доступ к сайту определяется настройками Vercel; приватность GitHub-репозитория сама по себе не делает опубликованный сайт приватным.

Информация о визуальных материалах — в `ASSETS.md`.
